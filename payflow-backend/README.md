# PayFlow Backend Service

PayFlow v1.0 REST API service built with NestJS 10, TypeScript, and PostgreSQL 16.

🚀 Prerequisites
- Node.js 20 LTS
- npm (v18+)
- PostgreSQL 16 (or Docker Compose)
